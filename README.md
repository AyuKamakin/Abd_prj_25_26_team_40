## **Правила работы с репозиторием**
📍 **Основное правило**    
В main нельзя работать напрямую! Все изменения делаются через ветки-задачи  
Одна ветка - один пользователь

🔄 **Процесс работы**    
1. Создаем ветку, если ее еще нет:  
- ветка создается от main
- шаблон нейминга на английском: сути задачи кратко\свои инициалы (step1\a-kuleshova)
- если создана впервые, пишем в чатик название ветки, чтоб ветки, относящиеся к одному степу имели одинаковый префикс

2. Работаем в ветке:
- В процессе работы почаще обновляем ветку с мастера
- Один коммит = одно логическое изменение
- Коммиты и PR пишем на русском
- Перед пушем обязательно обнови main и подтяни изменения
- Создаем PR в main без удаления рабочей ветки
- При финальном завершении работ добавляем Мишу в ревьюверы, он сам подтверждит мердж 

3. Апрув по пунктам:
- код читаемый и понятный
- имена переменных и функций понятные
- оставлены комментарии
- все файлы отвечают пунктам этапа проекта
  
🆘 **Конфликты**  
1. Смотрим с чьими файлами конфликт
2. Уведомляем коллегу, с кем конфликт
3. Совместно или самостоятельно решаем конфликт, как договоритесь со вторым автором
